Quest VR Launcher — GitHub Pages package

1. Upload the contents of this folder to the repository root (not the outer ZIP folder).
2. Commit to the main branch.
3. In GitHub, open Settings > Pages and set the source to GitHub Actions if it is not already selected.
4. Open Actions and wait for "Deploy to GitHub Pages" to finish.
5. The site URL will be:
   https://doctorgtstudios-spec.github.io/quest-vr-launchet/

Open the URL in Meta Quest Browser to try WebXR. WebXR immersive VR requires a
supported headset/browser and HTTPS; desktop preview does not prove headset support.

The main app is self-contained in index.html. The icon files are included for
its favicon references.
